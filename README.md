# Good Company

The pre-trip check-in that makes group travel feel like good company.

## MVP experience

A mobile-first, front-end prototype for the Good Company pre-trip check-in. It follows the supplied design direction: the coral day card, teal night card, ink linework, warm paper surfaces, warm editorial type, and a gentle, non-judgmental voice.

## Run it

Open `index.html` in a browser. No build step or dependencies are required.

## What’s in this prototype

- Trip name and group-size setup
- Invite screen with a copyable sample link
- Twelve-question Trip Check with progress and answer selection
- Deterministic demo travel-type and six-dimension result
- Preview-first travel-type cards in Story (1080×1920) and square (1080×1080) formats
- Explicit save, native share, and public Trip Check link actions; no automatic posting
- Share cards contain the archetype and brand only, never trip details or private answers
- Sample group dashboard with privacy-safe illustrative insights
- Three-step optional conversation flow with a group takeaway
- Local answer deletion control

Progress is stored in this browser’s local storage. This is a front-end prototype, not a live multi-person service: invitation links do not sync data between devices, the sample group is illustrative, and the scoring/archetype mappings are placeholders for product calibration. The Trip Check link uses the published app URL when available; local and repository source URLs are never copied as public links. A production MVP needs a backend, proper organizer/participant access, shared group data, retention/deletion handling, and privacy review before promising that individual answers stay private.

The supplied transparent Good Company mark is included at `assets/good-company-mark.png` and used directly in the prototype.
